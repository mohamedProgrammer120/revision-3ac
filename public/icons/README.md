# Icônes PWA

Remplace ces fichiers par de vraies icônes PNG :

- `icon-192x192.png` (192×192)
- `icon-512x512.png` (512×512)

## Générateurs recommandés

1. **[realfavicongenerator.net](https://realfavicongenerator.net)** — excellent
2. **[pwa-asset-generator](https://github.com/onderceylan/pwa-asset-generator)**
3. Ou simplement utilise Canva / Figma et exporte en PNG

Pour un look premium, utilise un fond sombre (#020617) + le logo 🎓 ou un symbole cyan.
